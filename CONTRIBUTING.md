# Contributing

Thanks for your interest in contributing to Awesome React Production Stack!

## Guidelines

Please ensure your pull request adheres to the following:

- **Search previous suggestions** before making a new one to avoid duplicates.
- **Make an individual pull request** for each suggestion.
- **Use the following format:** `- [Name](link#readme) - Description.`
- **Link to the GitHub repo** and add `#readme` at the end.
- **Keep descriptions short, simple, and objective.** No marketing language.
- **New categories or improvements** to the existing categorization are welcome.
- **Check your spelling and grammar.**
- **The pull request should have a useful title.**

## Quality Standards

To be included, a project should:

- Be actively maintained (commits within the last 6 months).
- Have clear documentation.
- Have a stable release or be widely used in production.
- Solve a real problem in the React production stack.

## Removing Entries

If a project is no longer maintained or has been superseded, it may be removed.

Thank you for your suggestions!
